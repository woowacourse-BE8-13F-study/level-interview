# 8기 레벨 인터뷰 (level-interview)

<details>
  <summary><strong>🚀 스터디 규칙</strong></summary>

1. 각 요일별(월~금) 발제자는 `자정 0시 이전` 오늘의 주제를 발제한다. [주제 발제 가이드](https://github.com/woowacourse-BE8-13F-study/level-interview/discussions/1)
2. 발제자를 포함한 모든 스터디원은 당일 `23시 59분 이전`에 해당 주제에 대한 답변을 작성한다. [주제 답변 가이드](https://github.com/woowacourse-BE8-13F-study/level-interview/discussions/2)
3. 모든 스터디원은 본인 발제 주제를 제외한 주 최소 4개의 주제에 대해 답변을 작성해야 하며, 각 주제에 대해서는 반드시 당일 `23시 59분 이내`에 작성한다.

<strong>📚 스터디 방향성</strong>
- 이상적인 학습 시간은 30분이며, 개인의 선호에 따라 학습 시간을 자유롭게 조정할 수 있다.
- 주제에 대한 코멘트 작성 방향은 **면접 대비** 및 학습 정리에 초점을 둔다.

<strong>💰 벌금</strong>
1. 토요일 0시 기준, 본인 발제 주제를 제외한 4개의 주제에 대해 당일 코멘트를 달지 않은 경우, 코멘트 1개당 **`벌금 10,000원`**
2. 주제 발제일 당일에 작성하지 않은 경우, 코멘트 1개당 **`벌금 5,000원`**
</details>
